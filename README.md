# 부동산 데일리 브리핑

Google 뉴스와 Naver 뉴스에서 매일 부동산 주요 뉴스를 모아 HTML 화면으로 보여주는 프로그램입니다.
Claude나 인터넷 AI 없이 동작하며, 별도 설치가 필요 없습니다(Windows 기본 PowerShell과 웹브라우저만 사용).

## 사용법

| 파일 | 역할 |
|---|---|
| `run_collect.bat` | 더블클릭하면 오늘 뉴스를 수집(약 1분)한 뒤 뷰어를 엽니다 |
| `viewer.html` | 뷰어. 브라우저로 열면 됩니다(인터넷 연결 없이도 열람 가능) |
| `register_schedule.bat` | 매일 07:30 자동 수집을 Windows 작업 스케줄러에 등록합니다. `register_schedule.bat 06:00`처럼 시각을 바꿀 수 있습니다 |
| `config.json` | 후보 키워드, 검색어, 수집 개수 같은 설정 |
| `data/` | 수집 기록(날짜별 `days/YYYY-MM-DD.json`), 로그 |

같은 날 여러 번 수집하면 그날 데이터는 마지막 수집 결과로 덮어씁니다. 지난 날짜는 그대로 남아 뷰어에서 조회할 수 있습니다.

## 동작 방식

1. **키워드 선정(연관도 분석)**: "부동산·아파트·주택 시장·부동산 정책"을 검색해 최근 24시간 기사 약 350건을 표본으로 모읍니다. 후보 키워드 33개마다 출현 기사 수, 키워드끼리 같은 기사에 함께 나온 횟수로 만든 네트워크의 PageRank 중심성, 최근 7일 평균과 비교한 모멘텀을 계산해 점수를 매깁니다. 기사 집합이 50% 넘게 겹치는 키워드는 빼서 서로 다른 주제 6개를 고릅니다.
2. **기사 수집**: 키워드마다 Naver(관련도순, 1일)와 Google News RSS(1일)를 검색합니다. 같은 이슈를 다룬 기사는 하나로 묶고, 화제도 상위 10건을 고릅니다.
3. **화제도(조회수 대체 지표)**: 포털은 기사별 조회수를 공개하지 않습니다. 그래서 다음 항목을 합산합니다.
   - 같은 이슈를 보도한 언론사 수
   - Naver "관련뉴스 N건" 묶음 크기
   - 두 포털에 모두 노출됐는지 여부
   - 검색 순위
   - **Naver "많이 본 뉴스" 랭킹 포함 여부**(실제 조회수 기반이며 가중치가 가장 큽니다)
4. **종합 요약(탑재형, 오프라인)**: 뷰어 안의 JavaScript가 처리합니다.
   - TextRank로 핵심 문장을 추출합니다. 화제도를 가중치로 쓰는 개인화 PageRank와 MMR 중복 제거를 사용합니다.
   - 키워드별로 2문장씩 요약합니다.
   - 구절마다 대상(가격·물량·거래)과 방향 표현을 짝지어 매매·전월세별 시장 지표 6개를 계산합니다. 가격은 상승/하락, 물량·거래는 증가/감소로 표시하며, 근거 기사가 3건 미만인 지표는 표시하지 않습니다.
   - 이슈어 빈도 분석, 일자별 추이, 급상승 이슈어를 보여줍니다.

5. **부동산 정책 탭**: 국토교통부(주택토지 분야·부동산 관련 제목)와 금융위원회(부동산·주택·대출 관련 제목) 보도자료를 매일 모아 누적합니다. 정부가 직접 쓴 요점, 담당부서, 조회수, 첨부 PDF 링크를 보여주고, 분야별로 자동 분류합니다. 저장 위치는 `data/policies.js`입니다.
6. **시기별 비교 (과거 기사 검색 탭)**: 매일 쌓인 수집 기록을 1일·1주·1달·3달·6개월·1년·3년·6년 전 시점별로 묶어, 검색어별로 기사 수, 핵심어, 대표 기사, 시장 지표가 어떻게 바뀌었는지 보여줍니다. 아직 기록이 없는 시기는 "기록 없음"으로 표시되고, 기록이 쌓이면 자동으로 채워집니다.

## 설정 팁

- `config.json`의 `candidates`에 키워드를 추가하거나 뺄 수 있습니다. `aliases`는 표본 기사에서 출현 여부를 셀 때 쓰는 동의어이고, `query`는 실제 검색어입니다.
- Naver 검색 화면 구조가 바뀌면 HTML 파싱이 깨질 수 있습니다. 그럴 때는 [Naver 개발자센터](https://developers.naver.com)에서 검색 API 키(무료)를 발급받아 `naverApi.clientId/clientSecret`에 넣으면 공식 API로 수집합니다.
- 수집 로그는 `data/logs/날짜.log`에 남습니다.

## 유의 사항

수집한 기사는 개인 열람 용도로 사용하세요. Google News RSS 약관은 개인적·비상업적 이용만 허용하고, Naver도 검색 결과의 자동 수집을 제한할 수 있습니다. 외부 배포나 상업적으로 이용하려면 공식 API나 별도 계약이 필요합니다.
